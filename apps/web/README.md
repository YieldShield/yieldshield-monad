# Historical Base / Robinhood frontend

This is the imported YieldShield frontend retained for provenance and reference. It is not deployed at monad.yieldshield.ai. Its stock assets, trading routes and earlier network settings do not establish support in the Monad product.

For the active app, use [`apps/monad-web/`](../monad-web/) and the [root setup instructions](../../README.md). The [repository guide](../../docs/REPOSITORY_GUIDE.md) distinguishes active code from historical material. Imported file hashes are recorded in [BASE_IMPORT.json](../../docs/BASE_IMPORT.json); the source history is preserved.

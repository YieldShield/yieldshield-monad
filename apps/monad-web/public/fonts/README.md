# Clarity fonts

The app self-hosts the unmodified Latin WOFF2 subsets of DM Sans (400–700) and Manrope (400–800). Retrieved from Google Fonts on 2026-09-15. Their SIL Open Font License notices are bundled beside the files.

- [DM Sans source](https://github.com/google/fonts/tree/main/ofl/dmsans)
- [Manrope source](https://github.com/google/fonts/tree/main/ofl/manrope)
- [Google Fonts CSS source](https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=Manrope:wght@400..800&display=swap)

Both files total 61,556 bytes. System fallbacks cover characters outside the Latin subsets. Production does not contact Google Fonts.

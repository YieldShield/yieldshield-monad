Live authenticated retrieval and a new user-signed publish remain unverified. [Original diagnosis](evidence/redstone-diagnosis.json), [recovery instructions](../REDSTONE_RECOVERY.md)

A fresh read-only 10-current-USDC quote returned **0.09993 MON**, spending **9.999996 USDC**, with a minimum of **0.09943035 MON**; a 20-USDC request was rejected as materially incomplete. Funding checks require current liquidity and fresh withdrawal prices/capacity before approval and again before deposit. Exact amounts preserve tiny remainders. The new token has no public faucet and the owner has none, so a new funded browser swap is still blocked. No current buy-then-protect journey or external demand is claimed. [Current deployment check](../evidence/kuru-current-deployment-20261011.json), [integration and token access](../KURU_INTEGRATION.md)
